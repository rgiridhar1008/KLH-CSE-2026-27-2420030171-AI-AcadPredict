## Abstract

Academic project management in educational institutions often faces challenges such as manual progress tracking, delayed identification of project risks, fragmented communication, and limited visibility into project status. Existing systems primarily focus on project administration and lack intelligent mechanisms for early risk detection. AI-AcadPredict is an AI-integrated academic project management and delay risk prediction platform that utilizes React.js, Spring Boot, MySQL, Python, FastAPI, JWT authentication, Docker, and a Random Forest machine learning model to analyze project data and predict project delay risk as Low, Medium, or High. Based on the prediction, adaptive notifications and alerts are generated to support timely intervention and improve project completion rates.

## Project Objectives

- Provide a centralized platform for academic project management.
- Track project progress and milestones effectively.
- Predict project delay risks using machine learning.
- Improve communication among students, faculty, and coordinators.
- Support early intervention through notifications and alerts.
- Improve project completion rates and monitoring efficiency.

- Provide feedback.

## AI Integration

### AI Objective

Predict project delay risk and enable early intervention.

### Input Features (X)

- Attendance Percentage
- Task Completion Percentage
- Pending Tasks
- Missed Deadlines
- Milestone Completion Percentage
- Study/Activity Hours
- Previous Academic Performance

### Output (Y)

**Project Delay Risk**

- Low Risk
- Medium Risk
- High Risk

### Machine Learning Model

- Algorithm: Random Forest
- Library: Scikit-learn
- Language: Python
- API Integration: FastAPI
